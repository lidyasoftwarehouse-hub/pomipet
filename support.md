

# Support

Thank you for using our application.

If you need help, have a question, experience a technical issue, or would like to provide feedback, please contact Lidya Software House.

## Contact

**Email:** lidyasoftwarehouse@gmail.com

When contacting support, please include:

- The name of the application
- Your device model
- Your iOS version
- A short description of the issue
- Screenshots, if helpful

Please do not send passwords, payment card information, or other sensitive information by email.

## In-App Purchases

If you experience an issue with an in-app purchase, please first try the **Restore Purchases** option inside the application, if available.

Payments and refunds for App Store purchases are handled by Apple.

For billing or refund requests, please use Apple's official purchase support channels.

## Response

We review support requests as soon as reasonably possible.
